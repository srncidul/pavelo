Hugo CMS

Hugo je populární generátor statických webů napsaný v jazyce Go.

Jedná se o open-source projekt vydávaný pod licencí Apache License 2.0. Vyniká především rychlostí generování výsledných statických HTML stránek.

Hugo funguje tak, že projde soubory s obsahem a tento obsah dosadí do připravených šablon a vygeneruje statické HTML stránky. Výsledný web tedy není dynamický web, nýbrž soubor statických HTML souborů. To má výhody z hlediska rychlosti načítání webu a také z pohledu bezpečnosti. Hugo podporuje Markdown syntaxi pro tvorbu obsahu.

Podporuje také vícejazyčné weby, úpravu obrázků, šablonovací systém. Je vhodný například pro menší firemní prezentace, blogy či weby s dokumentací softwaru.

Processwire

Tam, kde jsou potřeba vlastní nestandardní požadavky, nabízíme řešení vytvořené v CMS ProcessWire. I tyto stránky byly vytvořeny v Processwire, dále byl ještě použit framework UIkit 3.

ProcessWire je přívětivý, jednoduchý a přesto velice mocný a flexibilní Open Source CMS nebo spíše framework. Celý systém je od počátku také vícejazyčný.
